Simulado de versionamento de git

O Git é um sistema distribuído de controle de versão que registra o histórico de alterações no código-fonte de um projeto ao longo do tempo. Com ele, desenvolvedores podem trabalhar em equipe de forma simultânea e organizada utilizando ramificações (*branches*), o que permite testar novas funcionalidades, reverter erros e integrar mudanças com segurança sem comprometer a versão principal da aplicação.
